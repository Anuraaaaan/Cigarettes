# EN

**Cigarettes** adds cigarettes, vapes, and a nicotine addiction system to your server.

Using the configuration, you can create:

* cigarettes and vapes;
* custom items;
* custom recipes;
* nicotine withdrawal levels.

The plugin supports **Russian and English** and also allows you to create your own language files. _The selected language applies to the entire plugin and all players on the server and does not depend on each player's client language._ Specify the desired language file in `config.yml`.

Cigarettes also has optional support for ItemsAdder.

The plugin has a flexible configuration. Most settings can be customized to your needs.

### Plugin Commands

* `cigarettes reload` — reloads the plugin configuration;
* `cigarettes give <name> <amount> <player>` — gives a plugin item to a player;
* `cigarettes add <nicotine> <tolerance> <addiction>` — adds the specified nicotine, tolerance, and addiction values to a player's current values.

### Plugin Permissions

* `cigarettes.reload` — allows the use of `cigarettes reload`;
* `cigarettes.give` — allows the use of `cigarettes give`;
* `cigarettes.add` — allows the use of `cigarettes add`.

# RU

**Cigarettes** добавляет на сервер сигареты, вейпы и систему никотиновой зависимости.

С помощью конфигурации вы можете создавать:

- сигареты и вейпы;
- кастомные предметы;
- собственные рецепты;
- уровни никотиновой ломки.

Плагин имеет поддержку **русского и английского языков**, а также позволяет создавать собственные языковые файлы. _Выбранный язык применяется ко всему плагину и всем игрокам на сервере и не зависит от языка клиента каждого игрока._ Укажите нужный языковой файл в `config.yml`.

Также Cigarettes имеет необязательную поддержку ItemsAdder.

Плагин имеет гибкую конфигурацию. Большинство параметров можно настроить под себя.

### Команды плагина:
- `cigarettes reload` - перезагружает конфигурацию плагина;
- `cigarettes give <название> <количество> <ник>` - выдаёт игроку предмет плагина;
- `cigarettes add <никотин> <толерантность> <зависимость>` - добавляет параметры никотина, толерантности и зависимости к вашим.

### Также разрешения плагина:
- `cigarettes.reload` - позволяет использовать `cigarettes reload`;
- `cigarettes.give` - позволяет использовать `cigarettes give`;
- `cigarettes.add` - позволяет использовать `cigarettes add`.
